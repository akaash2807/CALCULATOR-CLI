# Python Calculator CLI App

## Project Overview
The Python Calculator CLI App is a command-line application developed using Python. It performs basic mathematical operations through an interactive menu.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Continuous calculations using a while loop
- Division-by-zero handling
- Invalid input handling
- Exit option

## Technologies Used
- Python
- Visual Studio Code
- Command Line Interface (CLI)

## Concepts Used
- Python Functions
- While Loops
- If-Elif-Else Statements
- User Input
- Exception Handling
- Break and Continue Statements

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python calculator.py
```
